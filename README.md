# 정이한 웹 포트폴리오

정이한의 AI파이썬랩 프로젝트를 소개하는 웹 포트폴리오입니다.

## 📁 파일 구조

```
portfolio/
├── index.html          # 포트폴리오 메인 페이지
├── style.css           # 스타일시트 (디자인)
├── script.js           # 상호작용 JavaScript (카드 클릭, 모달)
├── projects.js         # 프로젝트 데이터
└── README.md           # 이 파일
```

## 🚀 로컬에서 보기

간단하게 `index.html`을 웹 브라우저에서 열면 됩니다:
- 파일 탐색기에서 `index.html`을 더블클릭하거나
- 브라우저에서 `Ctrl+O` 후 파일 선택

## 🎨 주요 기능

- **프로필 헤더**: 이름, 학교, 역할, 사용 기술 태그
- **프로젝트 카드**: 4개 프로젝트를 카드로 표시 (2~5회차)
- **상세 모달**: 카드 클릭 → 프로젝트 상세 정보 표시
  - 소개, 만든 이유, 스크린샷, 주요 기능
  - 배운 점, 회고 (잘 된 점/아쉬운 점)
  - 앱 실행 버튼, GitHub 코드 보기 버튼
- **반응형 디자인**: 모바일/태블릿/데스크톱에서 모두 보기 좋음

## ✏️ 커스터마이징

### 프로젝트 정보 수정
`projects.js` 파일을 편집하여 프로젝트 정보를 변경할 수 있습니다:
- 각 프로젝트의 설명, 기능, 배운 점 등을 수정
- 새 프로젝트 추가 시 배열에 객체 추가

### 디자인 변경
`style.css`에서 색상, 폰트, 간격 등을 수정할 수 있습니다.
